## Обеспечение качества данных
Качество данных обеспечивается многоуровневой системой валидации.
На этапе приема Kafka Schema Registry проверяет схемы данных,
отсеивая некорректные записи.
Great Expectations мониторит статистические метрики - полноту данных,
свежесть и соответствие бизнес-правилам.
Для обнаружения дрейфа данных используется Evidently AI,
который отслеживает изменения распределений фич и генерирует алерты
при отклонениях. Feature Store обеспечивает консистентность фич
между обучением и инференсом. Data Lineage через OpenLineage дает
полную трассируемость данных от источников до ML-моделей.
Автоматические дашборды в Grafana показывают ключевые метрики качества,
а при критических сбоях срабатывают алерты в Slack и PagerDuty.
Процедуры восстановления включают retry механизмы для failed jobs и
backfill пайплайны для пересчета исторических данных при обнаружении аномалий.
