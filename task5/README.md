### Таблица ролей и уровней доступа

| Роль | Уровень доступа | Данные | Права |
|------|-----------------|---------|--------|
| **GoFuture Super Admin** | Глобальный | Все tenant'ы | Полный доступ ко всем данным, управление партнерами, системные настройки |
| **Partner Admin** | Tenant-level | Только свой tenant | Управление водителями, просмотр метрик, финансовые отчеты |
| **Partner Manager** | Tenant-level | Только свой tenant | Просмотр бронирований, управление промо-акциями |
| **Partner Driver** | Tenant-level | Только свои поездки | Просмотр своих заказов, статусов выплат |
| **Partner Passenger** | Tenant-level | Только свои поездки | История поездок, платежи, рейтинги |
| **Auditor** | Read-only global | Агрегированные данные | Просмотр compliance отчетов, аудит безопасности |
